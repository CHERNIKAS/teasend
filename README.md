# TeaSender

Автоматизация публикации объявлений в Telegram-чатах-барахолках от имени
личного аккаунта, с соблюдением правил каждого чата.

## Зачем

Вы состоите в десятках чатов, где объявления о продаже разрешены правилами, и
постите вручную. Это долго и легко сбиться: где-то можно раз в сутки, где-то —
раз в 6 часов. TeaSender ведёт правила по каждому чату и публикует за вас,
никогда не нарушая заданную вами частоту.

## Как это работает

1. Вы создаёте **приватный канал-черновик** и пишете туда объявления — обычными
   сообщениями, с премиум-эмодзи, фото, видео, альбомами.
2. TeaSender читает этот канал: каждое сообщение (или альбом) = шаблон.
3. Вы импортируете список своих чатов одной командой и отмечаете, где постить
   можно и с какой частотой.
4. Планировщик раскладывает публикации по дню в рамках правил каждого чата и
   публикует их от вашего аккаунта.
5. Бот присылает уведомления о доставке и об ошибках.

Объявление копируется как есть — премиум-эмодзи и альбомы сохраняются, потому
что мы пересылаем ваше же сообщение, а не пересобираем его.

## Границы

Инструмент рассчитан на чаты, где объявления **разрешены правилами**
(барахолки, доски объявлений, тематические площадки). Для каждого чата
хранится статус разрешения и заметка — источник разрешения.

Чего в проекте нет намеренно: мутаций текста «под человека», имитации набора,
ротации аккаунтов и прокси. Подробнее и почему — `docs/POLICY.md`.

Автоматизация личного аккаунта нарушает ToS Telegram. Риск ограничений
остаётся; проект минимизирует его честными средствами — строгим соблюдением
`FloodWait`, консервативными лимитами и правилами чатов. См. `docs/RISKS.md`.

## Быстрый старт

```bash
cp .env.example .env          # заполнить API_ID/API_HASH, BOT_TOKEN, ADMIN_USER_IDS
docker compose up -d db       # поднять PostgreSQL
pip install -e .
python -m teasender.tools.gen_key      # ключ шифрования сессии
python -m teasender.tools.login        # вход в аккаунт (интерактивно, один раз)
alembic upgrade head                   # схема БД
python -m teasender.tools.import_chats # импорт ваших чатов
python -m teasender.app                # запуск
```

Подробности развёртывания на VPS — `docs/DEPLOY.md`.

## Структура

- `src/teasender/config.py` — настройки.
- `src/teasender/core/` — перечисления, шифрование секретов.
- `src/teasender/db/` — модели SQLAlchemy (PostgreSQL).
- `src/teasender/telegram/` — Telethon: клиент, вход, импорт чатов, копирование.
- `src/teasender/services/` — правила чатов, планировщик дня, публикация.
- `src/teasender/scheduler/` — фоновые циклы (планирование, отправка).
- `src/teasender/bot/` — панель управления на aiogram.
- `src/teasender/tools/` — CLI: ключ, вход, импорт чатов.
