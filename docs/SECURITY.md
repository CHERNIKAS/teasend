# Безопасность

## Что самое ценное

Строка сессии Telethon = полный доступ к вашему Telegram-аккаунту. Это главный
секрет системы.

| Секрет | Хранение | Защита |
|---|---|---|
| Сессия Telethon | `data/session.enc`, зашифрована Fernet | Ключ отдельным файлом, не в git |
| Ключ Fernet | `data/secret.key` | Права 0600 (POSIX) / ACL (Windows), отдельный бэкап |
| Токен бота | `.env` | Не коммитить; при утечке — `/revoke` в @BotFather |
| 2FA-пароль | не хранится | Вводится только вами при `login` |

## Правила

1. Секреты не в git: `.env`, `data/`, `*.key`, `*.enc` — в `.gitignore`.
2. Ключ Fernet и база — в раздельных бэкапах. Одна база без ключа сессию не расшифрует.
3. Whitelist админов бота — по числовому `user_id`, не по username.
4. Секреты не попадают в логи (сессия, токен, пароль).
5. Docker: контейнер под non-root, `data/` — внешний volume, секреты через `env_file`.
6. Windows: `icacls data\secret.key /inheritance:r /grant:r "%USERNAME%:F"`; держите `data/` вне облачной синхронизации (OneDrive и т.п.).

## Если токен/сессия скомпрометированы

- Токен бота: `/revoke` у @BotFather, обновить `.env`, перезапустить.
- Сессия: завершите сессию в Telegram (Настройки → Устройства), удалите `session.enc`, пройдите `login` заново.
